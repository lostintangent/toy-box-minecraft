# Toy Box visual direction

Toy Box Minecraft is a playful, legible place to watch a real Channel work. The world should
feel assembled from a small set of well-made toy parts. Public conversation, tasks, artifacts,
and requests remain the purpose of the room; decoration helps the user find them.

## Materials and color

- Cream shells (`#FFF7E8`) and pale birch (`#EEDFB7`) carry most surfaces.
- Deep ink (`#18243A`) frames screens, storage bins, and the Toy Box mark.
- Coral (`#F47D5A`) marks connectors, controls, and small roof details.
- Mint (`#9BCDB8`) supplies the second toy accent and the robot display eyes.
- Keep the established status palette separate from identity color. Status dots and lamps
  explain activity; each member's own avatar color identifies them. Text also carries state.
- `assets-src/palette.json` owns generated colors. Preserve the contrast checks in
  `gen/ui_style.py`; UI text tokens must pass on every surface they are drawn on.

## Character system

Agents are interchangeable robot toys, not a fixed cast of people. Each robot has a cream
manufactured shell, an ink visor and articulated joint bands, and carries its member's own
avatar mark and color. `AvatarArt` draws every skin and portrait at runtime from the member's
public Channel avatar, and a stable hash of the member ID picks broad or slim arms, so names,
roles and colors always come from the live Channel. The Toy Box icon is generated by
`gen/brand.py`; no external illustration or font is required for it.

## Workshop

The workshop has a flat cream lid with daylight slots, light birch frames, modular ink panels,
coral connector edging, and six colored rooftop studs. A squared skylight covers the Channel
room. Three stacked toy blocks carry its status beacon. The entrance uses a flat welcome
canopy and a matching block mark. Modular storage replaces the masonry hearth.

Keep the inherited walking and station coordinates stable. Desk seats need a clear approach
cell, monitors must remain visible beside the agents, and paths between the Channel room,
desks, library, shared table, and benches must stay open. The room remains editable: the
existing Blueprint diff applies managed changes while preserving player edits.

Screens use generous spacing, cream paper panels, and dark ink text or legible light text on
ink glass. Use a single coral highlight for the current action. Names and public status should
be readable before tool or transcript detail. Private agent reasoning does not belong on a
public Channel monitor.

## Verification

1. Run `python assets-src/build.py --verify`. It validates resources, model references,
   texture geometry, contrast, and byte-identical output across three independent builds.
2. Sync with `python assets-src/sync.py`, then run `python assets-src/sync.py --check`.
3. Build the Java mod. Use the live fixture to inspect an exterior view, the Channel entrance,
   a populated task wall, a desk close-up, an open user request, the artifacts screen, and
   the workshop at night.

Check that public names come from the Channel, the six slots are recognizable without color
alone, controls remain legible, station movement has no obstruction, and roof details do not
hide the work surfaces. Retain upstream MIT attribution in the repository license and notices.
